# Python_Mathematical_logics
A Python project demonstrating predicate logic, logical quantifiers, relationships, and Boolean expressions using sets, functions, all(), and any().

{# Python Predicate Logic

## About the Project
This project demonstrates how to implement mathematical predicate logic using Python.

It represents relationships between people and evaluates logical statements using Python's built-in functions and data structures.

## Concepts Covered
- Python Sets
- Tuples
- Functions
- Boolean Expressions
- `all()` and `any()`
- Universal Quantifiers (∀)
- Existential Quantifiers (∃)
- Logical Negation (¬)
- Assertions and Logical Verification

## Relationships
The project uses four people:
- Ann
- Bob
- Cat
- Dan
Their relationships are represented using a Python set of tuples.

## Logical Problems
The program evaluates five statements:
1. Everybody loves somebody.
2. Somebody is loved by everybody.
3. Nobody loves everybody.
4. Everyone loves themselves.
5. Someone loves only themselves.

## How to Run
.Make sure Python 3 is installed.
.Run the following command:

```bash
python predicate_logic.py
```

## Technologies
- Python 3
- Visual Studio Code
- Git and GitHub

The objective is to understand how mathematical logic and quantifiers can be translated into executable Python code.
